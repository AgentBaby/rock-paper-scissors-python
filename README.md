# Rock, Paper, Scissors (Python)

A best-of-3 rock, paper, scissors game against the computer, built with Python and pygame.

## Features
- Live scoreboard (first to 3 points wins)
- Random computer moves
- Hover-effect buttons and simple icons drawn in code
- Play Again / Reset button

## How to run
1. Install Python 3
2. Install pygame: `pip install pygame`
3. Run: `python rockpaper.py`
